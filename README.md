# Court Radar

An at-a-glance view of live tennis court availability across South London.
One grid shows every court at every hour, across the six All Star Tennis
(Mindbody) locations and every LTA court-booking venue from Putney to Peckham
and Vauxhall to Norbury (Battersea Park included). New visitors start with no
venues, any time and any surface, and pick venues from Venues or the map.

Live at [court-radar-london.pages.dev](https://court-radar-london.pages.dev/).

## How it works

- **Only selected venues are requested.** Each venue loads on its own, so the
  grid fills in as answers arrive instead of waiting for the slowest one.
- **All Star venues load in the browser** straight from Mindbody's widget.
  LTA and ClubSpark venues (Battersea included) come through
  `/api/availability?venue=CC&date=YYYY-MM-DD`, which calls LTA's booking API.
- **Nothing is more than 60 seconds old.** The API caches each venue and date
  for 60 seconds in Cloudflare's cache, so many visitors cost the booking
  systems one request a minute. If a booking system stops answering, the venue
  shows an error rather than old availability. The page refetches anything over
  a minute old while it's on screen.
- **Choices are remembered.** Every change (venues, date, hours, surface,
  sort, view, collapsed venues) is saved in the browser and restored next
  time; a remembered date that has passed falls back to today. The view is
  also written to the URL so a link opens the same view, and a URL wins over
  saved choices.

URL parameters: `date` (YYYY-MM-DD), `v` (venue codes, e.g. `CC,BP`), `h` (start
hours, e.g. `18,19`), `match` (`any` to show courts free at any chosen hour
rather than all of them), `full=show` (show fully booked courts too),
`surface`, `view` (`map`) and `sort` (`free`, `near`).

LTA sometimes takes 30 seconds or more to answer. If it hasn't answered within
6 seconds, the server sends a second request and uses whichever answers first.

## Installing

Court Radar is a progressive web app: "Add to Home Screen" on iPhone, or
"Install app" in Chrome, gives it its own icon and full-screen window. The
service worker in `public/sw.js` keeps the app itself available offline but
never stores availability. Bump its `VERSION` when the list of app files
changes.

## Venues

`public/shared/venues.js` is the one list of venues. All Star venues are
written there by hand. LTA venues come from `public/shared/lta-venues.js`,
which is generated by searching LTA's court finder from points across South
London:

```bash
node scripts/find-lta-venues.mjs
```

Re-run it to pick up new venues. It keeps existing venue codes, so saved
choices and shared links keep working, and it leaves out venues that don't
take public bookings.

## Map

The map uses MapLibre GL with OpenFreeMap's vector tiles. Both are free and
need no account or API key.

## Code layout

- `public/shared/venues.js`, `public/shared/lta-venues.js`: the venues.
- `public/shared/mindbody.js`, `public/shared/lta.js`: one adapter per booking
  system, shared by the browser and the server.
- `public/js/`: the browser app. `model.js` (filtering and counting) and
  `prefs.js` (URL and saved choices) have no DOM code and are unit tested.
- `lib/availability.mjs`: the per-venue API with its cache, used by both the
  Pages Function in `functions/api/availability.js` and the local `server.js`.
- `scripts/find-lta-venues.mjs`: regenerates the LTA venue list.

## Run

Requires Node.js 20 or newer.

```bash
make run
```

Then open [http://localhost:3000](http://localhost:3000). For automatic
restarts while developing:

```bash
make dev
```

The local server caches in memory rather than in Cloudflare's cache.

## Deploy to Cloudflare Pages

In Cloudflare Pages, connect this repository and use:

- Framework preset: None
- Build command: leave blank (or use `exit 0`)
- Build output directory: `public`
- Root directory: repository root

The checked-in `wrangler.jsonc` contains the equivalent configuration. To test
the complete Pages deployment locally:

```bash
make pages
```

To deploy from the command line after authenticating Wrangler:

```bash
make deploy
```

## Test

```bash
make test
```

No packages or API keys are required.
